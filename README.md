# pramod-printers-general-shop
A responsive Hindi business website for Pramod Printers – General Shop, featuring printing services, invitation cards, online forms, AEPS/banking services, contact details, and a mobile-friendly navigation menu.
# प्रमोद प्रिंटर्स – जनरल शॉप

प्रमोद प्रिंटर्स – जनरल शॉप की आधिकारिक responsive business website। यह वेबसाइट ग्राहकों को printing services, निमंत्रण कार्ड, online forms, AEPS/banking services और संपर्क जानकारी एक ही स्थान पर उपलब्ध कराती है।

## 🌐 मुख्य सुविधाएँ

* Responsive और mobile-friendly design
* Fixed navigation header
* Mobile में right-side navigation menu
* बिना smooth scrolling के direct section jump
* Printing और general shop services की जानकारी
* निमंत्रण कार्ड की जानकारी
* Online form services
* AEPS / Banking services section
* WhatsApp संपर्क सुविधा
* हिंदी भाषा में user-friendly interface
* Custom logo और Devanagari font support
* Contact section और business details

## 🛠️ इस्तेमाल की गई तकनीकें

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Fonts
* Custom `.ttf` font

## 🚀 वेबसाइट चलाने का तरीका

1. Repository को clone या download करें।
2. सभी फाइलों और `assets` फोल्डर को एक ही project folder में रखें।
3. `index.html` फाइल को browser में खोलें।

```bash
git clone https://github.com/USERNAME/pramod-printers-general-shop.git
```

इसके बाद `index.html` को browser में open करें।
